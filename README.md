## 🔬 Flagship research — *SARS-CoV-2 Persistent Infection*

> **[`BakelLab/Persistent-Infection-Project`](https://github.com/BakelLab/Persistent-Infection-Project)** · 🔒 private lab repo (access on request) · primary maintainer

The computational backbone of my **PhD thesis**: a longitudinal analysis of within-host viral evolution and clinical implications across a persistent-infection cohort. End-to-end, database-to-figure, on HPC.

- **Mutation trajectory & entropy analysis** — curated mutation tables, missing-position masks, major/minor mutation event calls
- **Within-patient evolutionary rates** — pairwise accumulation + **root-to-tip (RTT)** regression with residual outlier detection
- **Selection & recurrence** — **dN/dS** summaries and recurrent-mutation heatmaps across genes
- **Clinical integration** — lineage timelines, **Ct-value trajectories**, and transmission/clinical timelines from PathogenDB-linked metadata
- **Stack:** Python (Jupyter) + R · SQL database connectors · Bash · Mount Sinai HPC (SLURM)

*Manuscript in preparation. Repository is private; happy to walk through methods and figures on request.*
